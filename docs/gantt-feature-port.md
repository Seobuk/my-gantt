## 이식된 기능 상세

### 1. CSV 내보내기 (`CSV 내보내기` 버튼)
- `WBS,이름,시작일,종료일,진행률(%)` 형식, WBS 번호로 계층 표현
- UTF-8 BOM 추가로 한글 엑셀에서 이름 깨짐 방지
- 상위(롤업) 행의 날짜·진행률은 파생값이라 비워서 내보냄
- 파일명: `gantt_YYYY-MM-DD.csv`

### 2. CSV/TSV 가져오기 (`CSV 가져오기` 버튼)
- 인코딩 자동 판별: UTF-16 BOM → UTF-8 → EUC-KR (한글 엑셀 레거시 대응)
- 구분자 자동 판별: 따옴표 밖 탭/쉼표 개수 다수결
- 날짜 파싱: `2026-08-06`, `2026.8.6`, `2026/08/06`, `2026. 8. 6.` → `YYYY-MM-DD`
- 달력 검증: `2026-02-30` 같은 무효 날짜는 미정 처리 (조용한 롤오버 방지)
- WBS 번호(`1.2.3`)로 계층 복원, 자식 있는 행의 날짜·진행률은 파생값으로 버림
- 가져오기 전 확인 다이얼로그 (개수·첫 항목 표시)

### 3. 기간(일) 직접 편집
- 상세 패널의 기간 표시를 숫자 입력으로 변경
- 시작일은 그대로 두고 종료일 = 시작일 + (기간 − 1)로 이동

### 4. 날짜 순서 보정 시점 변경
- `change`에서는 값 반영 + 막대만 다시 그림 (`repaint`)
- 시작 > 종료 순서 보정은 `blur` 시점에만 수행
- 연도 타이핑 도중("2026"을 칠 때 0002→0020→...) 중간값이 반대편 날짜를 덮어쓰는 버그 방지

### 5. 키보드 조작
- `↑`/`↓`: 행 선택 이동 (접힘·숨김 반영, 화면 스크롤 추적)
- `←`/`→`: 말단 작업 진행률 ±5%p
- `Tab`: 이름 수정 진입
- `Ctrl`+`D`: 기간(일) 수정 진입
- `Enter`+`Ctrl`/`Shift`: 하위/형제 추가
- 상세 패널 입력 중·이름 편집 중에는 가로채지 않음

### 6. 삭제 확인
- 삭제 버튼 클릭 시 `confirm()`으로 확인 (하위 항목 수 표시)

### 7. 이름 입력 중 연속 추가
- 이름 입력 중 `Enter`+`Ctrl`: 확정 후 하위 추가
- 이름 입력 중 `Enter`+`Shift`: 확정 후 형제 추가

## 아키텍처 원칙 준수 확인
- 단일 파일·무빌드·순수 vanilla JS 유지 (ES5 스타일)
- 이중 모드 저장(`init`/`saveLocal`/`pushServer`/600ms 디바운스) 미변경
- 일(day) 단위 유지, 데이터 스키마 변경 없음 (`data/wbs.json` 미수정)
- 색상은 기존 CSS 변수 사용, 라이트/다크 대응 유지
